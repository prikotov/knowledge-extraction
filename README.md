# Knowledge Extraction

Набор shell-скриптов для извлечения структурированных знаний из внешних материалов через [TasK API](https://task.ai-aid.pro).

Принимает URL, возвращает факты, цитаты и тезисы. Агент работает с источником любого размера, не загружая его целиком в контекст — вопросы, уточнения, поиск по фрагментам.

## Возможности

- **Загрузка** — статьи, YouTube-видео, видео- и аудиофайлы (Whisper-транскрибация), документы (PDF, DJVU, HTML)
- **Диалог** — вопрос → ответ с цитатами из источника, цепочка уточнений
- **Поиск по чанкам** — поиск фрагментов, близких по смыслу к запросу

## Как работает

```text
ingest → chat   (диалог — приоритет)
       → search  (поиск фрагментов)
```

### 1. Загрузка

```bash
./scripts/ingest.sh --source-url https://habr.com/ru/articles/1061876/
```

Возвращает `project_uuid`, `source_uuid`, количество документов.

### 2. Диалог

**Новый диалог:**

```bash
./scripts/chat.sh --source-url https://habr.com/ru/articles/1061876/
```

По умолчанию спрашивает «О чём этот материал?» и возвращает ответ.

**Уточняющий вопрос в том же диалоге:**

```bash
./scripts/chat.sh --chat abc-123 --question "Какие 4 убеждения разбирает автор?"
```

**Поиск по чанкам:**

```bash
./scripts/search.sh --source-url https://habr.com/ru/articles/1061876/ \
  --query "теория локуса контроля Роттера"
```

### 3. Результат

Агент оформляет полученные факты и цитаты под задачу: саммари, дайджест-карточка, research-заметка.

## Настройка

Для работы нужен доступ к [TasK API](https://task.ai-aid.pro). Два файла на уровне папки, откуда запускаются скрипты:

### `tasK_token.json`

```json
{
  "access_token": "ваш-токен-доступа"
}
```

### `tasK_config.json` (опционально)

```json
{
  "api_url": "https://api.ai-aid.pro/v1"
}
```

Если файла нет — используется `https://api.ai-aid.pro/v1` по умолчанию.

Скрипты ищут эти файлы, поднимаясь от своего расположения вверх по дереву папок до первого совпадения. Это позволяет хранить токены в корне проекта или статьи, не дублируя их в папке со скриптами.

### Проверка статуса загрузок

Если материал долго обрабатывается (YouTube-видео могут идти десятки минут), можно загрузить без ожидания и проверить позже:

```bash
./scripts/ingest.sh --check
```

Вывод:
```
youtube.com/watch?v=... → processing ✦
github.com/.../wsff.md → ready
Изменений: 1
```

## Интеграция с AI-агентами

Этот проект оформлен как навык (skill) для AI-агентов — [pi coding agent](https://github.com/earendil-works/pi-coding-agent), Claude Code, Codex и других.

Файл `SKILL.md` содержит frontmatter и инструкции: когда использовать навык, как вызывать скрипты, как вести диалог с материалом и оформлять результат.

Чтобы подключить навык, создай симлинк в `.agents/skills/` агента:

```bash
ln -s ~/MyProjects/knowledge-extraction .agents/skills/knowledge-extraction
```

## Безопасность

- `tasK_token.json` и `tasK_config.json` — в `.gitignore`, **никогда не коммитятся**
- `tasK_project.json` — состояние проекта (UUID, маппинги URL), тоже в `.gitignore`
- Сами скрипты не содержат секретов, токен передаётся через переменную окружения `TASK_API_TOKEN`

## Связь с TasK

Knowledge Extraction работает поверх [TasK](https://task.ai-aid.pro) — платформы для работы с AI-агентами и документами ([документация API](https://docs.ai-aid.pro/redocly)). TasK обеспечивает:

- Загрузку и индексацию источников (веб-страницы, YouTube, файлы)
- Чанкинг и эмбеддинги
- RAG-диалоги (Retrieval-Augmented Generation) с источником
- Полнотекстовый поиск по чанкам

Для доступа к TasK API — [напиши Дмитрию](https://prikotov.pro/obo-mne).

## Скрипты

| Скрипт | Назначение |
|---|---|
| `scripts/ingest.sh` | Загрузка материала в TasK, ожидание готовности |
| `scripts/chat.sh` | Диалог с материалом через Chat API |
| `scripts/search.sh` | Поиск чанков через Chunks API |

Подробное описание опций каждого скрипта — в `SKILL.md`.
